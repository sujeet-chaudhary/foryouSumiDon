# Proposal website

Open `index.html` in any browser. No build step or server needed.

## Folder structure
proposal/
├── index.html      page structure
├── css/style.css   look and feel
├── js/script.js    story, blush effect, buttons (edit CONFIG at the top)
└── README.md

## Personalise
- Edit the CONFIG block at the top of js/script.js (her name, your name, the letter lines).
- Or share a link like: index.html?to=Aisha&from=Ravi
- To share online, upload the folder to Netlify, GitHub Pages or Vercel.
